# khannagaurav.github.io

V2

Portfolio site for Gaurav Khanna, Lead Security Engineer (Network & Cloud Security).

A single self-contained `index.html`: no build step, no framework, no external
requests. Served by GitHub Pages from the root of `main`.

## Editing

All content is in `index.html`. The sections, in order:

- Hero and headline stats
- Core security domains
- Firewall and security platforms (Palo Alto, Prisma Access, Check Point, WAF/ADC)
- Professional experience (tabbed by employer)
- Technical stack
- Certifications and education
- Contact

Open `index.html` in a browser to preview changes locally.

## Publishing

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.
